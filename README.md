# 航海家 1 號｜一光日之外

以 NASA 任務影像、WebGL 3D 星空與音樂，探索一光日的距離。

線上網站：https://maskywg.github.io/voyager-one-light-day-20261108/

## 功能

- 3D 星空深度飛行與滑鼠視差，支援暫停和減少動態。
- NASA 歷史照片、旅程章節切換與影像放大。
- 《A Small Light from Earth》配樂，點擊播放、音量與循環。
- 一光日里程碑倒數、訊號往返示意、手機版與社群分享預覽圖。

## 本機預覽

執行 `python3 -m http.server 8765`，開啟 http://localhost:8765/ 。

## 來源與使用範圍

NASA / JPL-Caltech 影像出處見 `assets/credits.json`。主視覺為藝術想像圖。
配樂為網站擁有者提供的 Suno 音樂；非黃金唱片收錄內容。
本專案未授予第三方素材或配樂的額外再利用權利。

資料查核日期：2026-11-08。里程碑為 NASA 預計時刻，並非即時遙測；訊號動畫經時間壓縮。本站非 NASA 官方網站。詳細科學來源見頁尾。
